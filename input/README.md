# Upload Android project ZIPs here

Upload one complete Android Gradle project ZIP into this folder, then commit it to the `main` branch.

That commit automatically triggers **Build Android APK**.

Requirements:
- Include `gradlew` and `gradle/wrapper/gradle-wrapper.properties`.
- Include `settings.gradle` or `settings.gradle.kts`.
- Include at least one Android application module with an `assembleDebug` task.
- Upload one ZIP per commit so the workflow can identify the intended project.

**Public repository warning:** this repository is public. ZIPs committed here are publicly accessible. Do not upload private code, credentials, signing keys, keystores, API keys, or personal data.
